
# C Programming

A structured collection of C programming concepts, practical examples, and problem-solving exercises.

This repository documents my journey of learning C programming, strengthening programming fundamentals, and developing logical problem-solving skills.

## 📚 Topics Covered

| Topic | Description |
|---|---|
| Basics | Syntax, variables, data types and operators |
| Conditionals | if, if-else, nested if and switch |
| Loops | for, while and do-while |
| Patterns | Star and number patterns |
| Functions | Function declaration, definition and calling |
| Recursion | Understanding recursive functions |
| Arrays | One-dimensional and two-dimensional arrays |

## 🚀 How to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/Harshit-Varshney-Dev/c-programming.git
   ```

2. Navigate to the project directory:

   ```bash
   cd c-programming
   ```

3. Compile a C program:

   ```bash
   gcc filename.c -o program
   ```

4. Run the program:

   ```bash
   ./program
   ```

   On Windows:

   ```bash
   program.exe
   ```
